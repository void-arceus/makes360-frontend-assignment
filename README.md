# 🚀 Makes360 Homepage Redesign

A modern, fully responsive redesign of the Makes360 homepage built using **React** and **Tailwind CSS**.

The goal of this project was to improve the UI/UX, enhance layout structure, and create a more modern, user-friendly, and visually appealing homepage while maintaining clarity and usability across all devices.

---

## 🌐 Live Demo

👉 https://void-frontend-assignment.netlify.app/

---

## 🎯 Objective

- Improve UI/UX design of the original homepage
- Create a modern and professional layout
- Ensure full responsiveness across devices
- Improve visual hierarchy and readability
- Build a clean, scalable component structure

---

## ⚙️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript (ES6+)
- Vite

---

## ✨ Features

- ⚡ Fully responsive design (mobile, tablet, desktop)
- 🎨 Animated hero section with typewriter effect
- 🌈 Modern gradient background with subtle animations
- 🧭 Interactive navbar with dropdown menus (desktop + mobile)
- 🧩 Structured sections:
  - Services
  - Why Choose Us
  - Milestones
  - Certifications
  - Testimonials
  - Gallery
  - Awards & Recognition
  - Contact Form
  - Footer
- 🖼️ Image gallery with navigation controls
- 📩 Fully designed contact form UI
- 💡 Clean component-based architecture

## ▶️ Run Locally

Follow these steps to run the project on your local machine:

### 1. Clone the repository

git clone https://github.com/your-username/your-repo-name.git

### 2. Navigate to the project folder

cd your-repo-name

### 3. Install dependencies

npm install

### 4. Start the development server

npm run dev

### 5. Open in browser

The app will run on:
http://localhost:5173
